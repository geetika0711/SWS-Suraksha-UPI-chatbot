# SWS-Suraksha-UPI-chatbot
SWS Suraksha bot — a trilingual (English/Hindi/Punjabi) UPI fraud-safety chatbot by Stalwarts World School. Paste a message or screenshot flags for QR scams, fake KYC alerts, PIN phishing &amp; more, with instant Safe/Caution/Danger verdicts. Runs fully in-browser, no server or API needed.
